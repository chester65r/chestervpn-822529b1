# Tunnel Console — launch plan

Saved 2026-10-31. Ordered by how soon each action can bring the first users.

1. **Add /sitemap.xml** — to do. The SEO scan (2026-10-31) found no sitemap;
   adding one helps search engines discover the page and enables indexing
   tracking in Search Console. Only failing finding from the scan.
2. **Connect a custom domain** — to do. Directory listings (SaaSHub, BetaList)
   reject free subdomains, and a own domain looks more trustworthy when
   developers decide whether to run someone's VPN code. Project settings →
   Domains.
3. **Showcase post for Android developers** — to do. r/androiddev (or
   r/learnandroid) post showing the Android blueprint angle: "I built a
   dashboard that generates a working VpnService Kotlin skeleton." Needs the
   author's own account; write it personally (HN/Reddit penalize AI-text and
   drive-by promotion). Expect honest technical feedback more than volume.
4. **Show HN** — to do, after the site has a domain. Fits a tryable technical
   tool; requires an established HN account and a personally written post.
5. **DevHunt free listing** — to do. Dev-tools-only launchpad; free queue is
   long (~6 months), so submit early; $19 paid launch picks the week.
6. **AlternativeTo / SaaSHub listings** — to do, after the custom domain.
   Slow-burn discovery as alternatives to VPN client apps.
7. **Connect Google Search Console** — to do. Confirms indexing and shows which
   searches bring impressions once the sitemap is live.

Skipped / not possible yet: paid ads (no steady users to amplify, and the tool
is free with no sign-up goal); Product Hunt (better after a domain and some
feedback from the developer communities).
